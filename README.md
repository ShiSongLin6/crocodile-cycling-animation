# Crocodile Cycling 鳄鱼骑车动画

一只戴头盔的鳄鱼骑自行车，纯 SVG + SMIL 动画，单文件、零依赖、双击即看。

## 打开方式

直接双击 `index.html`，或把它拖进浏览器。没有 JS 库、没有网络请求。

## 动画细节

- 前后车轮各 1s 一圈，膝盖与脚掌按 8 帧关键帧踩踏，与曲柄 1.2s 同步
- 鳄鱼身体前后小幅摆动，尾巴、背部鳞片、肚皮纹路分层绘制
- 每 4s 眨眼一次，头盔、腮红、速度线、滚动地面标记营造前进感
- 两层云朵以不同速度平移

## 来源

由 Claude Opus 5.5 生成的单页作品，原为本地临时演示（`07_CrocodileCycling_鳄鱼骑车动画`）。开源存档，可自由取用。
